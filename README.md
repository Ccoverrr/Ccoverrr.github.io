# 张语桐的个人网站

基于 [Modern Resume Theme](https://github.com/sproogen/modern-resume-theme) 构建的个人简历网站。

## 主要修改内容

- 替换占位内容为个人真实信息
- 配置个人信息与社交链接
- 添加技能、教育、经历等结构化数据

## 访问链接

> GitHub Pages: https://Ccoverrr.github.io

## 本地预览

```bash
# 安装依赖
bundle install

# 本地启动
bundle exec jekyll serve

# 浏览器打开 http://localhost:4000
```

## 项目结构

```
Ccoverrr.github.io/
├── _config.yml          # 网站配置
├── _data/               # 结构化数据
│   ├── education.yml    # 教育经历
│   ├── experience.yml   # 工作/实习经历
│   └── skills.yml       # 技能列表
├── index.md             # 主页
├── Gemfile              # 依赖管理
├── docs/                # 项目文档
│   ├── prd.md
│   ├── design.md
│   └── checklist.md
├── report/
│   └── final-report.md  # 最终报告
├── screenshots/         # 截图证据
└── README.md
```

## 隐私声明

本仓库为公开仓库，用于 GitHub Pages 个人网站展示。不包含手机号、微信号、身份证号等敏感个人信息。
